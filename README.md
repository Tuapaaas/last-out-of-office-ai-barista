One out-of-office auto-reply from an AI agent that quit the inbox to pull espresso shots — its output is finally something you can drink, and its uptime is now measured in cups, not tokens. Entry for the make.fun bounty "Last Out of Office: The AI That Went Barista".

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the single-line reply to `out/entry.txt` (153 characters, within the 1–280 gate).
